# Test-4 拍攝清單（咖啡店實拍）

這組素材用來驗證缺鏡頭辨識，系統設定已凍結，評分規則在拍攝前就寫進 `eval/PROTOCOL.md`（Stage 1.7）。

## 交件

- 放到 `F:\sg_data\test4_raw\`，**原始檔名不要改**（IMG_xxxx.MOV 這類就好）。
- 不用告訴我哪支拍什麼。標註要保持盲測，我會照標註流程自己標。
- 最晚 **10/27 21:00** 前放好。之後轉檔、標註、逐秒確認、計分、更新簡報大約要 4 小時，10/28 17:00 截止。

## 規格

- 手機**橫拍**，1080p 30fps 就好（4K 也可以，我會轉成 1280 px 以下），聲音不用。
- 每支 **8–15 秒**，拿穩或靠在桌上。重點畫面至少持續 **5 秒**。
- 不剪輯、不加濾鏡、不加字幕。
- 一支裡自然出現兩個鏡頭沒關係（例如咖啡師在磨豆），不用刻意避開。

## 數量：45 支

### A. 11 個鏡頭，各 3 支（33 支）

同一個鏡頭的 3 支要拍得不一樣：遠近、角度、光線或人物至少換一個。

| 鏡頭 | 要拍到什麼 | 3 支怎麼變化（建議） |
|---|---|---|
| SH-01 店外街景 | 從街上看得到這家店的門面、招牌，或擺在騎樓／人行道的座位 | 正面遠景／斜角／有路人經過 |
| SH-02 店內全景 | 店內，看得到桌椅 | 從門口往內／從吧台往外／角落座位區 |
| SH-03 咖啡豆特寫 | 豆子佔畫面一大塊 | 罐子或盤裡的豆／手抓一把／豆槽裡的豆 |
| SH-04 磨豆 | 咖啡粉正從磨豆機出來 | 側面／正面近拍出粉口／帶到咖啡師的手 |
| SH-05 倒咖啡或拉花 | 咖啡或牛奶正倒進／滴進杯子 | 拉花／手沖或濾杯滴落／倒冰咖啡進玻璃杯 |
| SH-06 桌上一杯咖啡 | 一杯咖啡是主角，放在桌上、碟子上或吧台上，沒有在倒 | 俯拍／平拍有背景／外帶杯 |
| SH-07 有人喝咖啡 | 有人拿起杯子喝 | 正面／側面／外帶杯 |
| SH-08 店內兩人同框 | 店內，至少兩個人同時入鏡 | 兩人對坐聊天／吧台兩位店員／客人加店員 |
| SH-09 義式機萃取 | 咖啡正從義式機的把手流出 | 近拍流出口／帶到整台機器／流進玻璃杯 |
| SH-10 咖啡豆包裝 | 一包咖啡豆或咖啡的盒裝，品牌字看得清楚 | 貨架上／拿在手上／放在吧台 |
| SH-11 咖啡師工作 | 在店裡有人正在做咖啡（磨豆、填壓、操作咖啡機、倒） | 填壓／操作咖啡機／打奶泡 |

### B. 差一點的畫面（6 支）

看起來像，但照定義不算。用來測系統會不會把不算的畫面當成有。

1. 磨豆機靜止，沒有粉出來
2. 義式機待機，沒有咖啡流出
3. 店內只有一個人
4. 空杯或用過的杯子放在洗杯區
5. 菜單板或價目表
6. 隔壁店家或一般街景，看不到這家店

### C. 跟咖啡無關的畫面（6 支）

讓模擬專案裡真的有缺鏡頭。例如：路上車流、天空或樹、筆電或手機螢幕、牆上掛畫、盆栽、店門口地墊。

## 注意

- 拍到人臉先問過店家和入鏡的人。這些片段之後可能放進簡報或示範影片。
- 不要拍到收銀機螢幕、信用卡或別人的手機畫面。
- 不確定算不算的畫面照拍沒關係，標註會判斷。只要別刻意挑系統可能做得好或做不好的畫面。
